Ayuda práctica

Estamos al otro lado.

Si algo no funciona, cuéntanos cómo reproducirlo usando exclusivamente datos ficticios.

Contactar con soporte

Las incidencias del proyecto son públicas. Necesitas una cuenta de GitHub para publicar una consulta; no hace falta ninguna cuenta para usar la extensión.

Abrir una consulta

No compartas datos personales, prompts originales, documentos, contraseñas o capturas de conversaciones reales.

La revisión no aparece

  1. Comprueba que estás en chatgpt.com, claude.ai o gemini.google.com.
  2. Abre el icono de PrivadoListo y activa la protección.
  3. Recarga la pestaña si estaba abierta cuando instalaste la extensión.
  4. Abre una conversación y comprueba el estado del editor en el popup.
  5. Prueba con Mi DNI ficticio es 12345678Z y pulsa Enviar o Enter.

Si la web ha cambiado, PrivadoListo puede no reconocer el editor. Revisa manualmente el texto antes de enviarlo y comunícanos la plataforma afectada.

Hay un aviso incorrecto

Desmarca ese valor al revisar. Si quieres continuar sin sustituir ninguno, pulsa «Enviar sin proteger», confirma la decisión y después pulsa Enviar tú.

Recuperar el original

Tras proteger, usa «Recuperar original» durante el minuto siguiente. Si ya has editado el resultado, se mostrará una copia para que puedas recuperar lo que necesites sin sobrescribir tus nuevas ediciones.

Qué incluir en una incidencia

  • Versión de PrivadoListo y Chrome.
  • Plataforma afectada.
  • Pasos para reproducir, resultado esperado y resultado observado.
  • Un ejemplo inventado y sin información personal.
