# PrivadoListo

Web pública, política de privacidad y soporte de PrivadoListo.

Procesamiento local de determinados datos sensibles antes de enviarlos a servicios de IA compatibles. Gratis, sin cuentas y sin servidores de procesamiento de mensajes.

Sitio: https://jons0023-spec.github.io/privadolisto-site/

La extensión está completando su validación previa a publicación. Esta web no implica aprobación ni disponibilidad en Chrome Web Store.

Archivos estáticos sin JavaScript, trackers, fuentes externas ni formularios de recopilación. Publicación con GitHub Pages desde main/raíz. Soporte mediante Issues; utilizar solo ejemplos ficticios y nunca publicar información personal.
